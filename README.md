# RailwayReservationDB
A web-based Railway Reservation System developed using ASP.NET Web Forms, C# and SQL Server LocalDB.
## Features

- Home Page
- Search Train
- Train Details
- Railway Reservation
- Passenger Details
- Booking Confirmation
- My Booking
- SQL Server Database Connectivity

## Technologies Used

- ASP.NET Web Forms
- C#
- SQL Server LocalDB
- ADO.NET
- Visual Studio

## Project Flow

Home → Search Train → Reservation → Passenger Details → Booking Confirmation → My Booking
